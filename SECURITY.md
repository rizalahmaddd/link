# Kebijakan Keamanan

## Melaporkan Celah Keamanan

Mohon **jangan** melaporkan celah keamanan lewat issue publik.

Laporkan secara privat lewat tab **Security → Report a vulnerability** di repository ini (GitHub Private Vulnerability Reporting), atau hubungi kami langsung via kontak resmi:

- **WhatsApp**: [+62 857-7777-5477](https://wa.me/6285777775477)
- **Website**: [solusikoding.com](https://solusikoding.com)

Sertakan:
- Jenis celah keamanan dan potensi dampaknya,
- Langkah terperinci untuk mereproduksi masalah,
- Versi atau commit yang terdampak.

Laporan akan ditinjau dan ditanggapi secepatnya. Setelah perbaikan dirilis, pelapor akan dicantumkan di catatan rilis bila berkenan.

## Versi yang Didukung

Perbaikan keamanan hanya dirilis untuk versi terbaru di branch `main`.
